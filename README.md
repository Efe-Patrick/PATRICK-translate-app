# 🚀 PatrickTranslateApp

**PatrickTranslate** is a fast, lightweight, and modern desktop application built with Electron.js. It allows users to capture any region on their screen, instantly extract text using OCR technology, and translate it in real-time.

## ✨ Features

- 📸 **Screen Region Capture (OCR):** Select any area on your screen (games, videos, PDFs, or images) to recognize and extract text instantly using `tesseract.js`.
- ⚡ **Real-Time Translation:** Seamlessly convert captured or manually typed text into your target language.
- 🎨 **Modern Dark UI:** Clean, minimalist dark-mode user interface designed for daily desktop use.
- 🛠️ **Cross-Platform Foundation:** Built on top of Node.js and Electron.

---

## 🛠️ Built With

- **[Electron.js](https://www.electronjs.org/)** - Desktop Application Framework
- **[Tesseract.js](https://tesseract.projectnaptha.com/)** - Pure Javascript OCR Engine
- **[Node.js](https://nodejs.org/)** - Runtime Environment
